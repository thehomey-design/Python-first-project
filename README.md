# Python-first-project
Testing my first repository - String Indexing

## Code Example
```python
my_string = "hello world"
print(my_string[0])  # Prints: h
```

## Explanation
- `my_string` contains the text "hello world"
- `my_string[0]` gets the character at index 0, which is 'h'
- String indexing in Python starts at 0
